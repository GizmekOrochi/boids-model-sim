# ModelBoids
Generated by Vextra CLI.

**ModelBoids** is a C++ boids (flocking) simulation project focused on clean architecture, modular core logic, and extensibility.  

## Build & Compilation

The project is built using a simple **GNU Make–based build system**.

### Requirements
- C++17 compatible compiler (`g++` recommended)
- SFML development libraries

Install dependencies on Debian/Ubuntu:

sudo apt update
sudo apt install libsfml-dev

### Build :
make

The compiled executable will be generated in: bin/ModelBoids

### Run :
make run

### Clean :
make clean
