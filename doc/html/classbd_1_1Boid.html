Detailed Description

Représente un agent unique boid dans la simulation.

Un Boid encapsule l'état physique minimal requis par la simulation : sa position dans l'espace et son vecteur vitesse. Les règles comportementales opèrent sur ces valeurs pour produire le mouvement de nuée.
