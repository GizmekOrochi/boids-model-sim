Detailed Description

Contexte d'exécution pour le calcul des règles.

  • Cette structure regroupe toutes les références nécessaires (voisins, prédateurs, obstacles) pour qu'une règle puisse calculer sa force sans avoir une signature de méthode trop complexe. Elle est recalculée pour chaque boid à chaque frame.
