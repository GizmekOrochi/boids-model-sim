Detailed Description

template<typename T>
class bd::DynamicArray< T >

Un conteneur de tableau à redimensionnement dynamique simple.

Template Parameters
TType des éléments stockés dans le tableau.

Cette classe implémente un tableau dynamique minimal avec une gestion manuelle de la mémoire. Elle fournit des fonctionnalités de base telles que la croissance dynamique, l'insertion d'éléments, l'accès indexé et le nettoyage des éléments stockés.
