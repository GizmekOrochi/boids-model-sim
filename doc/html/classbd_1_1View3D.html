Detailed Description

Moteur de rendu 3D simplifié ("Software Renderer").

  • Cette classe gère toute la pipeline graphique : transformation du monde vers la caméra, projection perspective (3D -> 2D) et dessin des primitives (lignes, triangles) directement via SFML.
